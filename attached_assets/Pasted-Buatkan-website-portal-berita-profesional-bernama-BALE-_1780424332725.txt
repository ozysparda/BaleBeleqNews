Identitas:

	•	Nama: BALE BELEQ NEWS
	•	Slogan: Informasi • Budaya • Aspirasi
	•	Warna utama: Hijau, Merah, Putih
	•	Logo menggunakan Bale Beleq sebagai identitas utama
	•	Fokus berita: Desa, Pemerintahan, Budaya Sasak, Aspirasi Warga, Pendidikan, UMKM, Sosial Kemasyarakatan

Tambahkan sistem autentikasi dan manajemen pengguna profesional untuk website portal berita BALE BELEQ NEWS.

Persyaratan:

	1.	Saat website pertama kali dijalankan dan database masih kosong:
	•	Tampilkan halaman Setup Wizard.
	•	Hanya muncul jika belum ada akun Super Admin.
	•	Setelah akun Super Admin dibuat, halaman setup otomatis dinonaktifkan permanen.
	2.	Halaman Setup Wizard:
	•	Nama Lengkap
	•	Email
	•	Password
	•	Konfirmasi Password
	•	Tombol “Buat Website”
	3.	Setelah setup selesai:
	•	User pertama otomatis menjadi SUPER_ADMIN (Owner).
	•	Redirect ke Dashboard Admin.
	4.	Sistem Login:
URL:
/admin/login
Field:
	•	Email
	•	Password
Fitur:
	•	Remember Me
	•	Forgot Password
	•	Logout
	•	Session Management
	5.	Role System:
SUPER_ADMIN
	•	Kelola seluruh website
	•	Kelola pengguna
	•	Membuat Editor
	•	Membuat Wartawan
	•	Menghapus pengguna
	•	Mengubah role pengguna
	•	Mengakses pengaturan website
EDITOR
	•	Review berita
	•	Approve berita
	•	Publish berita
	•	Edit semua artikel
WARTAWAN
	•	Menulis berita
	•	Mengedit berita sendiri
	•	Menyimpan draft
	•	Tidak dapat publish
	6.	Menu Dashboard:
Dashboard
Berita
Kategori
Media
Pengguna
Pengaturan
Logout
	7.	Halaman Pengguna:
Tombol:
	•	Tambah Pengguna
Form:
	•	Nama
	•	Email
	•	Password
	•	Role
	8.	Workflow Berita:
Wartawan membuat berita
↓
Status = DRAFT
Editor Review
↓
Status = PENDING_REVIEW
Editor Approve
↓
Status = PUBLISHED
Berita tampil di website publik
	9.	Keamanan:
	•	Password wajib di-hash menggunakan bcrypt
	•	Middleware proteksi route admin
	•	Role-based access control
	•	CSRF protection
	•	Rate limiting login
	•	Audit log aktivitas pengguna
	10.	Database Prisma:

model User {
id
name
email
password
role
createdAt
updatedAt
}

enum Role {
SUPER_ADMIN
EDITOR
WARTAWAN
}

	11.	Buat seed data contoh:

SUPER_ADMIN:
Email: owner@balebeleqnews.com
Password: Owner123!

	12.	Jika sudah ada akun SUPER_ADMIN di database:
	•	Halaman setup tidak boleh dapat diakses lagi.
	•	Redirect ke halaman login.
